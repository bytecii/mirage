Create a token in [HF Models setup](/home/setup/hf_models), then register it on
an existing `ws`. Commands: [Python](/python/cli/hf) ·
[TypeScript](/typescript/cli/hf).

<Tabs>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    from mirage.commands.cli.builtin.hf import HF

    ws.register_cli("hf", HF, {"token": "hf_..."})
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { HF } from '@struktoai/mirage-node'

    ws.registerCli('hf', HF, { token: 'hf_...' })
    ```
  </Tab>
</Tabs>

A Hub mount reads; `hf` also writes. Use a write token to upload, delete,
create repositories, or create/delete tags. A read token is enough to download
files or list tags. To edit a Hub file, download it into a local mount, edit it
there, then upload it. A Hub write is a commit, so edits happen through the CLI.
