## Credentials

### 1. Create a Discord Application

1. Go to https://discord.com/developers/applications
1. **New Application** -> name it (e.g., "Mirage")

### 2. Create a Bot

1. **Bot** in the left sidebar
1. **Reset Token** -> copy the **Bot Token**
1. Under **Privileged Gateway Intents**, enable:
   - **Message Content Intent** (required to read message content)

### 3. Invite the Bot to Your Server

1. **OAuth2** -> **URL Generator** in the left sidebar
1. Select scopes: `bot`
1. Select bot permissions: `Read Messages/View Channels`, `Read Message History`
1. Copy the generated URL and open it in a browser to invite

### 4. Set Environment Variables

```bash
# .env.development
DISCORD_BOT_TOKEN=MTIx...
```

This is a dotenv file entry. Load it in your application or export the value,
then pass it to `DiscordConfig`.

## Optional CLI permissions

The read-only VFS setup above is enough to browse messages the bot can see. If
you register the [Discord CLI](/home/setup/cli/discord), add only the server
permissions needed by its commands, then open a new invite URL or update the
bot's role:

| Commands or path | Additional permission or setting |
| --- | --- |
| `send`, `edit` | Send Messages |
| `poll` | Send Messages and Send Polls |
| `react` | Add Reactions |
| `thread-create` | Create Public Threads and Send Messages in Threads |
| `delete` for messages from other users | Manage Messages |
| `members` or the VFS `members/` directory | Enable the Server Members Intent under **Privileged Gateway Intents** |

Channel overrides can still deny a permission granted to the bot's server
role. The bot can edit only messages it authored.

For Python configuration, see the [Python Discord VFS](/python/vfs/discord) page.
