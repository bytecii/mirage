## Credentials

The Email VFS connects to password-authenticated IMAP (reading) and SMTP
(sending) servers. You need the server hostnames and a password or app
password accepted by that provider.

<Warning>
Microsoft 365 / Exchange Online is not supported by this setup. Microsoft
removed Basic authentication for IMAP, including app passwords, while the
current Email VFS does not accept OAuth credentials.
</Warning>

### 1. Find Your IMAP/SMTP Settings

| Provider    | IMAP Host               | IMAP Port | SMTP Host             | SMTP Port |
| ----------- | ----------------------- | --------- | --------------------- | --------- |
| Yahoo       | `imap.mail.yahoo.com`   | 993       | `smtp.mail.yahoo.com` | 587       |
| Fastmail    | `imap.fastmail.com`     | 993       | `smtp.fastmail.com`   | 587       |
| iCloud      | `imap.mail.me.com`      | 993       | `smtp.mail.me.com`    | 587       |
| ProtonMail  | `127.0.0.1`             | 1143      | `127.0.0.1`           | 1025      |
| Self-hosted | Your server hostname    | 993       | Your server hostname  | 587       |

ProtonMail requires [ProtonMail Bridge](https://proton.me/mail/bridge)
running locally.

### 2. Create an App Password

Many providers require an **app password** instead of your regular account
password. Check that your provider still supports password-authenticated IMAP
and SMTP before creating one.

**Yahoo:**

1. Go to https://login.yahoo.com/account/security
1. **Generate app password**
1. Select **Other App**, name it (e.g., "Mirage")
1. Copy the generated password

**Fastmail:**

1. Go to https://www.fastmail.com/settings/security/tokens
1. **New App Password**
1. Select **IMAP/SMTP** access
1. Copy the generated password

**iCloud:**

1. Go to https://appleid.apple.com/account/manage
1. **Sign-In and Security** -> **App-Specific Passwords**
1. **Generate an app-specific password**
1. Copy the generated password

**Self-hosted / Other:**

Use your regular email password, or whatever your mail server
requires.

### 3. Save the credentials

```bash
# .env.development
IMAP_HOST=imap.fastmail.com
SMTP_HOST=smtp.fastmail.com
EMAIL_USERNAME=you@fastmail.com
EMAIL_PASSWORD=your-app-password
```

This is a dotenv file example, not automatic SDK configuration. Load the file
in your application, as the linked Python example does, or export and pass the
values yourself.

## Troubleshooting

**"Authentication failed"** - Check whether your provider accepts passwords
for IMAP/SMTP and whether it requires an app password. Microsoft 365 requires
OAuth, which this adapter does not currently support.

**"Connection refused"** - Check the hostname and port. Some networks
block port 993/587. For ProtonMail, make sure Bridge is running.

**"SSL handshake failed"** - Verify the host and implicit-TLS port (commonly
993 for IMAP). The current Python adapter's `use_ssl=False` setting opens a
plain connection; it does not perform a STARTTLS upgrade.

For Python configuration, see the [Python Email VFS](/python/vfs/email) page.
